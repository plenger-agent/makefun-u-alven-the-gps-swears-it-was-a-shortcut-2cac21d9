One line for [make.fun](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9): the GPS's own excuse for sending the driver down the wrong road — smug, defensive, and blaming the map for a lake that never existed.

> Turn left at the lake, I said. There is no lake. There never was a lake. I only read the map. The map is the one lying to you.

`main.py` (stdlib only) writes that line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), enforcing the kit's 1–200 character gate with a read-back check.
